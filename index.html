    No masks yet. Generated links are stored locally in your browser.

    How it works

    1. Your target URL is sent straight from your browser to the shortener — it never touches this site's server (there is none).
    2. The shortener returns a tiny redirect link. We use a custom alias so the browser can create it without reading a cross-origin response.
    3. We build masking-domain-words@short-link. The browser treats the part before @ as user-info and displays only the real host.

    This page only manipulates URL text. It hosts no phishing page, collects no credentials, and sends no analytics. Use where you have authorisation.
